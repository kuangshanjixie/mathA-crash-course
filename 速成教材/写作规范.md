# 《从能算到能证》章节写作规范（中央厨房）

> 本文件是全书章节的唯一标准。任何新章节必须与本规范、`ch01.html`（样板章）、`ch0m.html`（证明操作系统）保持一致。起草前必读：`速成教材/ch01.html` 全文 + `ch0m.html` 全文。

## 0. 读者与目标

读者：学过高数、线代、离散、概率的非数学专业学生，冲刺全国大学生数学竞赛数学专业 A 类初赛（数分 50% / 高代 35% / 解几 15%，6 道纯证明大题，分步给分）。目标：速成但不浅——概念来龙去脉串起来，同时建立五种能力：符号、题目翻译、类型识别、考法定位、计算能力。语言：中文。语气：像一个经验丰富的学长在讲，干净、直接、有画面感；禁止空洞鼓励和"让我们一起……"式废话。

## 1. 文件与技术规范

- 位置与命名：`速成教材/chNN.html`（数分 ch01–ch10，高代 ch11–ch21，解几 ch22–ch26）。
- 头部模板：完整复制 `ch01.html` 的 `<head>`（KaTeX CDN 三个标签原样）与 `.bookbar`、`.chapter-kicker`、`<h1>` 结构。
- **转义铁律**：HTML 正文里数学式中的 `<` 一律写 `&lt;`（`>` 可保留）。KaTeX 用 `$...$` / `$$...$$`。
- **SVG 里禁用 `$...$`**：`<text>` 内用 Unicode（ε、sup、≤、⟹），KaTeX 不处理 SVG。
- **JS 规则**：章内脚本用内联 `<script>` 置于 `</body>` 前；字符串内部引号用「」不用 ASCII `"`；写完必须 `node --check` 通过。翻卡功能：先 `<script src="assets/quiz.js"></script>`，**再** `registerQuiz(...)`（顺序反了会静默失效）。
- 样式类在 `assets/style.css`，禁止新增内联样式表；如需新组件样式，沿用现有类组合。
- 图片：示意图一律手写内联 SVG（参照 ch01 的天花板图），不用外部图片。

## 2. 章节骨架（九段，顺序固定）

1. **本章导览**（`.exam.box`）：在整张卷子上的位置（分值/频率/出处，数据从 `速成教材/真题索引/` 取）；学完你能 ①②③④（能力目标，对标五轨）；前置要求。
2. **§1 开场谜题**（`.hook.box`）：一个具体、反直觉的问题，制造认知痒点再给工具（3B1B 式）。谜题必须具体到数/图/现象，禁止抽象提问。本章主角要从谜题里"长"出来，动机讲透。
3. **§2 直觉与图像**（`.vision.box` + 至少一张内联 SVG）：先看见再定义。
4. **§3 精确定义**（`.def` + `.symbol.box` 逐符号朗读表）：定义精确给出；逐符号表三列：符号片段 / 出声读 / 它在干什么。配一个 `.think`（先动手，自己推一个对称定义或补一个简单推导，折叠答案 `.answer`）。
5. **§4 翻译轨**：2–3 个"标准动作"（`.trans.box`：题面原句 → 可执行条件 → 用在哪一步、值多少分）+ **翻译练功房** 6–8 条双向互译（自然↔符号、判断、找坑，折叠答案带易错点评）。
6. **§5 类型识别**（`.recog.box`）：题面信号 → 反射 表（6–8 行）。
7. **§6 考法定位**（`.exam.box`）：表格：出处（届/题号）/ 本题考点扮演什么角色 / 分值权重；一段话总结规律。数据必须来自真题索引，禁止编造。
8. **§7 关系网**：一张 SVG 地图（形状约定：三角=来源动机、圆角矩形=公理/定义、矩形=定理、六边形=方法动作、椭圆=应用出口；箭头标关系词；带图例）+ `.net.box` 画面感锚点表（每个节点一句画面）+ 与已学知识的焊接点。
9. **§8 例题**（2 道，按"按总纲拆解"格式，见 §3）→ **§9 配套题** → **§9.5 熟练度训练场** → **§10 六方向自测卡** → 间隔复习 → `.chapnav`。

## 3. 例题格式（最重要的质量线）

每道例题两层，禁止只给抛光证明，也禁止"第一反应→试错→小实验"式小剧场：

```
<div class="mind" data-tag="按总纲拆解（程序见第 0.5 章）">
  【拆目标】结论的逻辑形态 → 查拆目标总表得骨架（说明是哪一型）
  【盘点】每个已知条件展开成"产出清单"（写明哪条产出口后在哪儿用）
  【会师】倒推链：要证 A ⟸ 只需证 B ⟸ …… ⟸ 库存第几条；标注工具编号
           （工具一 倒推法 / 二 误差预算 / 三 特殊化侦察 / 四 量词否定 /
             五 生成序列 / 六 划归 / 七 极端原理 / 八 辅助函数）
  【定型】提示卷面怎么写、倒推痕迹删除
</div>
（需要时插 .keymove 深色条：把本例的通用动作命名钉出来；
 需要倒推计算时插 .scratch 草稿纸框）
<div class="calc box" data-tag="卷面书写">…分步给分格式，步骤右侧 <span class="step-score">（N 分）</span>，
 末尾 .aside 书写点评（哪步是分点、跳步为什么归零）…</div>
```

拆解要真实、通用、可迁移：每个动作都要能指出它属于程序哪一步、是通用规则的哪一条（如"∃ 在 ∀ 后 → 构造量必须依赖 ε"）。

## 4. 配套题（§9）

- 模仿题 ×2（`.lv1`）：照例题格式可解；答案折叠，带步骤分和易错点。
- 变式题 ×2（`.lv2`）：需要换一个动作或组合两个动作；答案给思路+证明。
- 真题节选 ×1（`.lv3`）：从 `速成教材/真题索引/` 选与本章直接相关的题，先给 2–3 个梯子问题（折叠"梯子参考答案"），再给"官方解答全文（转录自官方参考答案）"（折叠），结尾复盘：本题用了本章哪个动作 + 一句"转录自第 N 届官方 PDF"。若索引中没有完全贴合的题，选最近的并说明如何改编，**禁止虚构真题**。
- 所有题目前提醒一次铁律：先写后看。

## 5. 熟练度训练场（§9.5）

- 训练一 · 翻卡快测：8–10 张卡（概念反射 + 快速判断 + 公式默写提示），用 `registerQuiz("chNN-drill", [...])`。
- 训练二 · 计时默写：2–3 项（定义、核心定理、证明骨架），给时间标准和过关标准（连续两天全对）。

## 6. 六方向自测卡（§10，`.selftest`）

六项：=（定义默写）/ ←（它从哪来）/ →（它带来什么）/ ∈（三个实例）/ ≠（最易混的一对区分）/ 动机（为何要有它）。每项配折叠"对照"。不是阅读理解，是默写测试。

## 7. 交互小部件（widget）

每章 1 个（`.widget`），vanilla JS + 内联 SVG，主题：本章最反直觉的那个点（如 sup 探索器之于确界）。要求：有 2 个可拖动控件、实时反馈文本、3 个"玩出这三个体验"任务。数学逻辑必须正确。

## 8. 验收清单（交稿前自查）

1. `node --check` 全部内联脚本通过；
2. 全文扫描：数学式里无裸 `<`（合法 HTML/SVG 标签除外）；
3. 九段齐全；例题有按总纲拆解；练功房 ≥6 条；翻卡 8–10 张且 quiz.js 在 registerQuiz 之前；
4. 数学内容精确：定义、定理、例题计算、quiz 答案全部核对过；
5. 考法定位与真题节选的数据来自真题索引文件；
6. `.chapnav` 前后章链接正确（前一章文件名、后一章写"撰写中"或已存在的文件名）。

## 9. 返回报告格式

完成后返回：文件路径、九段齐全自查、用到的真题出处清单、widget 主题、你对本章数学内容最不确定的 1–2 个点（供主审查重点复核）。
